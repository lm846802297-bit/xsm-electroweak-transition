4. **Conventions.** Minkowski hard timelike invariant, Feynman +i0, NST positive inverse-propagator self-energy, D=4−2ε and MS-bar. 5. **Assumptions.** 4D zero temperature; one real singlet plus SM fields as in NST with vacuum singlet VEV shifted to zero and tree scalar potential convention. No independent determination of the full Yukawa or top width; a tree bW decay is only an absorptive normalization control.

Verify the exact equal-invariant/mass threshold and below/above branch sign, retain predicted D-times-pole term, and recover tree bW width within 1e-55 from the optical projection.
